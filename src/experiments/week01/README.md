# Week 1 environment and smoke scripts

- `habitat_pointnav_smoke.py`: repository evidence script used for the five-action PointNav smoke test.
- `habitat_scene_render_smoke.py`: historical direct Habitat-Sim scene-render smoke script.
- `habitat_vlnce_smoke.py`: historical Habitat/VLN-CE import and data-path smoke script.
- `torch_cuda_smoke.py`: historical PyTorch CUDA smoke script.

These scripts validate environment capabilities only. Their outputs are not learned-policy performance evidence. The verified Week 1 evidence is under [`../../results/week01/`](../../results/week01/), with the summary in [`../../../docs/Week01.md`](../../../docs/Week01.md).
